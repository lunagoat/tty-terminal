# Changelog

## 0.1.0

- Kitty engine with native inline image support.
- Linux VGA console font and palette, with borderless window and fullscreen modes.
- TOML settings for rows, columns, font size, cursor, scrollback, and startup directory.
- One-pixel font zoom shortcuts and clipboard support.
- Native installation, Arch package recipe, and GitHub source release workflow.

This is the first public release candidate. Tested on CachyOS with Kitty 0.48.2.
